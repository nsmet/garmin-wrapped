# Editorial story sequences — content only

These are **narrative logic examples**, not production copy or design mockups. All quantities except the verified 2025 audit counts are deliberately omitted because the user has not supplied measured values.

## Hybrid HIIT + running — based on known 2025 activity counts

1. “Your 2025 in motion.” [opening]
2. “141 recorded activities.” [yearly foundation]
3. “Five sports made the year.” [sport diversity]
4. “HIIT and running: 60 and 52 sessions.” [dual identity]
5. “HIIT: your 60-session chapter.” [sport introduction]
6. **Conditional:** “The time your heart spent in high-intensity zones.” [requires validated zone coverage; omit otherwise]
7. “Running: your 52-session chapter.” [sport introduction]
8. **Conditional:** “Your longest recorded run.” [requires actual recorded distances for all runs]
9. “Strength, indoor cycling and rowing were part of the mix too.” [secondary sports; known counts 13, 12, 4]
10. “Your year was more than one discipline.” [finale]

If advanced metrics are absent, replace conditional beats with *different verified* habit or peak stories; do not include the bracketed concepts as empty placeholders. If still sparse, shorten the sequence.

## Cycling-dominant — hypothetical, no specific user measurements

Opening → annual activity count → *verified* cycling share and hours → longest ride → climb story when ascent valid → power story when measured → cycling subtypes such as gravel vs indoor → a contrasting secondary discipline → surprise training habit → verified finale.

## Single-sport runner — hypothetical

Opening → annual activity count → running as most-recorded → cumulative distance → longest run → weekly running frequency → pace comparison **only if matched** → route memory if approved → verified PR → finale.

## HIIT and strength — hypothetical

Opening → sport mix → verified HIIT/strength headline → HIIT intensity-zone time if HR recorded → HIIT weekly consistency → strength set/rep story if workout metadata complete → verified load progression within one identical exercise, otherwise omit → less obvious supporting sport → finale.

## Golf — hypothetical sparse metadata

Opening → number of recorded golf sessions → golf time/active months → optional verified course diversity → finale. **Do not** show rounds won, strokes, handicap improvements or scores unless a tested golf data source actually provides them.

## Multisport race — hypothetical

Opening → count of distinct completed multisport events → verified leg breakdown → actual transition time when recorded → event-specific HR or elapsed duration → other training disciplines → finale. Avoid counting event parents *and* swim-bike-run legs as independent total activities.
